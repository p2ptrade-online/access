# Restaurant POS Capacitor Dashboard

A mobile-first POS analytics dashboard with an iOS-native feel, built with React, Vite, Recharts, and Capacitor.

## Quick Start

```bash
npm install
npm run dev
```

## Build Web + iOS

```bash
npm run build
npx cap add ios
npx cap sync
npx cap open ios
```

> After opening Xcode, select your device and run the app.
